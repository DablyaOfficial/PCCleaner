# PCCleaner

Небольшая программа для Windows 10/11: показывает всё, что установлено на компьютере, и всё, что запускается само, и даёт удалить или отключить лишнее.

Один exe-файл, установка не нужна.

## Что умеет

**Вкладка «Программы»**

- Показывает приложения Windows (в том числе предустановленные: Copilot, Clipchamp, Teams, Карты и т. п.) и обычные программы из реестра, включая скрытые системные компоненты.
- Делит всё на категории:
  - **Мусор** — известные навязанные приложения, удаляются без последствий;
  - **Предустановлено** — прочие приложения Microsoft из комплекта Windows;
  - **Программа** — то, что вы ставили сами;
  - **Осторожно** — драйверы, библиотеки, кодеки, компоненты;
  - **Защищено** — части Windows, Магазин, общие библиотеки. Отметить для удаления нельзя.
- Удаляет отмеченное. Приложения Windows удаляются для всех пользователей и убираются из предустановки, чтобы не вернуться у новых учётных записей. У обычных программ запускается их собственный деинсталлятор. Игры Steam передаются на удаление в Steam.

**Вкладка «Автозапуск»**

- Показывает четыре источника: разделы реестра `Run`, папки автозагрузки, планировщик заданий и службы сторонних программ. Последние два не видны в диспетчере задач — так программы запускаются «в тихую».
- Отключает и включает выбранное. Ничего не удаляется: записи реестра и папок отключаются тем же способом, что в диспетчере задач, задания переводятся в «Отключено», службы — в режим «Вручную».

В обоих списках есть поиск, фильтры и сортировка по щелчку на заголовке столбца.

## Как пользоваться

1. Скачайте `PCCleaner.exe` и запустите. Windows спросит права администратора — без них удалять программы нельзя.
2. Отметьте галочками лишнее (кнопка «Отметить мусор» отмечает всю категорию «Мусор»).
3. Просмотрите отмеченное и нажмите «Удалить выбранное...». Программа покажет список и спросит подтверждение.

Журнал действий пишется в `PCCleaner.log` рядом с exe.

## Перед тем как удалять

- **Проверяйте список глазами.** Категория «Мусор» определяется по списку названий, а не по тому, пользуетесь ли вы программой. В неё попадают, например, «Почта и Календарь», новый Outlook, Bonjour.
- **Оставьте включённой точку восстановления.** Галочка стоит по умолчанию; если что-то пойдёт не так, систему можно откатить.
- **Не трогайте «Осторожно» без причины.** Там драйверы видеокарты и звука, Visual C++ и .NET — без них перестанут запускаться другие программы.
- **Удалённые приложения Windows** возвращаются из Microsoft Store.
- Службы и задания самой Windows, а также Microsoft Defender программа не показывает и не отключает.

## Ограничения

- Проверялась на Windows 11 Pro. На Windows 10 должна работать, но не проверялась.
- Exe не подписан: SmartScreen или антивирус могут предупредить при первом запуске.
- Автозапуск приложений из Магазина Windows не сканируется.
- Интерфейс только на русском языке.

## Сборка из исходников

Ничего устанавливать не нужно: используется компилятор C#, входящий в Windows.

```bat
src\build.bat
```

Получится `PCCleaner.exe` в корне папки. Вся логика находится в `src\PCCleaner.ps1`; `src\Launcher.cs` — оболочка, которая встраивает этот скрипт в exe и запускает его без окна консоли.

Скрипт можно запустить и без сборки:

```powershell
powershell -ExecutionPolicy Bypass -File src\PCCleaner.ps1
```

Сканирование без окна и без каких-либо изменений в системе:

```powershell
powershell -ExecutionPolicy Bypass -File src\PCCleaner.ps1 -ScanOnly
```
